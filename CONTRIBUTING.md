# Contributing to DiaNav

Thank you for your interest in contributing to DiaNav! This project handles confidential automotive diagnostic data, so we have specific guidelines to ensure security and quality.

## 🔒 Security First

**CRITICAL**: This project processes confidential automotive diagnostic data. Please ensure:

- ✅ **NO confidential data** in pull requests or issues
- ✅ **NO real diagnostic codes** or proprietary information
- ✅ **NO sensitive images** or documents
- ✅ **Use sample data only** for testing and development

## 🚀 How to Contribute

### 1. **Fork the Repository**
```bash
git clone https://github.com/your-username/DiaNav.git
cd DiaNav
```

### 2. **Create a Feature Branch**
```bash
git checkout -b feature/your-feature-name
```

### 3. **Make Your Changes**
- Follow the existing code style
- Add tests for new features
- Update documentation as needed
- Ensure all tests pass

### 4. **Commit Your Changes**
```bash
git commit -m "feat: add your feature description"
```

### 5. **Push to Your Fork**
```bash
git push origin feature/your-feature-name
```

### 6. **Create a Pull Request**
- Use the provided PR template
- Describe your changes clearly
- Link any related issues

## 📋 Development Guidelines

### Code Style
- **Python**: Follow PEP 8 standards
- **TypeScript**: Use ESLint and Prettier
- **CSS**: Follow BEM methodology
- **Git**: Use conventional commit messages

### Testing
- Write unit tests for new features
- Ensure all existing tests pass
- Test with sample data only

### Documentation
- Update README.md if needed
- Add inline comments for complex logic
- Document any new API endpoints

## 🔐 Security Guidelines

### Data Handling
- **NEVER** commit real diagnostic data
- **NEVER** include confidential images
- **ALWAYS** use sample/mock data for testing
- **ALWAYS** validate data sanitization

### Code Review
- All PRs require security review
- Ensure no data leakage possibilities
- Verify proper error handling
- Check for potential vulnerabilities

## 🏷️ Issue Labels

- `bug`: Something isn't working
- `enhancement`: New feature or request
- `documentation`: Improvements to documentation
- `security`: Security-related issues
- `good first issue`: Good for newcomers
- `help wanted`: Extra attention needed

## 📞 Getting Help

- **Issues**: Use GitHub issues for questions
- **Discussions**: Use GitHub discussions for general topics
- **Security**: Use private channels for security issues

## 🏆 Recognition

Contributors will be recognized in:
- README.md contributors section
- Release notes
- Project documentation

Thank you for contributing to DiaNav! 🚀
